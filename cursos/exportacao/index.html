Sobre este projeto

📅 Histórico da exportação

A plataforma Moodle do Curso Popular Defensoria (env1.cursopopulardefensoria.com.br) foi desativada em 10 de junho de 2026. Antes da desativação, todo o conteúdo público foi exportado via scraping e convertido neste site estático.

Backups completos do banco de dados, arquivos e configurações estão armazenados de forma segura e podem ser restaurados se necessário.

🆕 Código aberto — faça um fork

O código de scraping, geração do site e os dados JSON estão disponíveis publicamente no GitHub. Você pode fazer fork, adaptar para outro Moodle, ou reutilizar os dados livremente.

🔗 https://github.com/cursopopulardefensoria/landing-page-react

☁ Infraestrutura e hospedagem

As páginas HTML são hospedadas no GitHub Pages, gratuitamente.

Os materiais em PDF e slides (638 arquivos, ~365 MB) estão armazenados no AWS S3 (static.cursopopulardefensoria.com.br), em conta privada financiada por Rafael Santos.

Os vídeos no YouTube são de responsabilidade e gestão da equipe do Curso Popular Defensoria.
